# Homepage hero background — spring / summer / fall

`home-hero-porch.jpg` (1024x768, original file, uncropped) is the Penthouse
porch photo used as the mybransonvacation.com homepage hero background for
spring, summer and fall. Archived Nov 10, 2026 when Christmas backgrounds were
previewed. The original also stays at
public/property-photos/penthouse/aaa-fall-porch.jpg (property cards and the
fall guide use it). Christmas hero: public/images/seasonal/christmas/home-hero-porch-christmas.jpg.
To restore, set the hero <img> src in src/app/page.tsx back
to `/property-photos/penthouse/aaa-fall-porch.jpg`.
